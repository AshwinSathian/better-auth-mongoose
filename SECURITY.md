# Security Policy

## Supported versions

Only the latest published minor version of each package (`better-auth-mongoose`, `better-auth-mongoose-tenant`) receives security fixes. There is no long-term-support branch for older versions, so please stay current.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting: go to the [Security tab](https://github.com/AshwinSathian/better-auth-mongoose/security) of this repository and select **"Report a vulnerability"**. This opens a private channel with the maintainer and avoids exposing the issue before a fix ships.

Please include:

- The affected package and version
- A minimal reproduction (a failing test is ideal)
- The potential impact as you understand it

You should expect an initial response within a few days. This is a solo-maintained open-source project, not a funded security team. Please be patient, and thank you for reporting responsibly.

## Scope

This policy covers `better-auth-mongoose` and `better-auth-mongoose-tenant` themselves. Vulnerabilities in `better-auth` or `mongoose` should be reported to those projects directly.
